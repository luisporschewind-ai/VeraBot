# 提示组件实验室

日期：2026-10-11。阶段：自有组件与实验室，尚未迁移正式页面。

## 目的与范围

克制、简短、柔和的提示，每条都由现有小 Bot 参与表达。先试验文案、Bot 状态、样式、动画和交互，再决定正式页面如何接入。入口为「调试 → 实验 → 提示组件实验室」，登录页与设置页的调试入口均可进入。

这次新增组件、实验室、场景盘点与验证工具，在 DebugView 增加导航。应用按原有流程启动，实验室通过调试入口进入并可返回。没有替换正式提示、改系统通知策略或添加依赖；实验按钮不会发请求、写剪贴板、申请通知权限或改变业务数据。

## 组成与职责

- `Core/UI/Notices/NoticeQueue.swift`：纯值队列，FIFO、按操作 key 去重 / 更新、待显示队列限长、过期 timer 身份校验。
- `Core/UI/Notices/BotNotice.swift`：内容模型与页面范围的 Observable center。直接使用 `BotAvatarState`，不另建 Bot 状态系统；业务操作由宿主处理。
- `Core/UI/Notices/BotNoticeCard.swift`：Bot 卡片、样式与顶部宿主。卡片复用 `RobotAvatarView`、主题语义色和触感开关。
- `Features/Settings/NoticeLab/`：自由试验、交互场景、现有功能场景目录、代码索引。

默认使用柔和实底，40 点 Bot，22 点圆角，0.32 秒轻滑 / 淡入。可比较材质背景，调整尺寸、圆角、速度、停留时长、按钮，手动选择全部现有 Bot 状态。可单独试验组件深浅色，不修改应用外观设置。没有全屏遮罩；横幅宽度上限为 560 点，适应 iPad。

背景另提供「液态玻璃」：iOS 26 使用系统 `glassEffect(.regular, in:)`，沿用卡片圆角，由系统处理玻璃边缘和光影，避免叠加实底、自绘边框与阴影。较早系统回退为轻透材质。原生 API 依据：[Apple 文档](https://developer.apple.com/documentation/swiftui/view/glasseffect(_:in:))。

已移除 `--notice-lab` 直达启动方式。实验室只作为调试页的导航目标，保留真实的上一级页面；此处修正了旧直达模式把实验室作为根页面、没有上一级页面的问题。

Bot 动作表达一次后，停在现有 reduced-motion 算法的代表性表情；连续工作状态观察 4.8 秒后也静止。状态变化或重播重新播放。这样常驻提示无需一直运行共享头像的动画时钟，系统减少动态效果也能保留状态含义。

`RobotAvatarView` 增加默认关闭的局部 `motionReduced` 参数供提示使用；原有调用不受影响，系统减少动态效果始终优先。

## 使用规则与生命周期

- 临时操作结果可以采用顶部横幅，持续过程采用页面状态，字段校验靠近字段，空状态解释页面为何没有内容。
- 删除、发送、授权等决定仍需明确确认；实验室可比较系统确认面板。系统通知只提供应用内示意，不仿冒真实通知，不申请权限。
- 同 key 同内容重复触发不重新计时；同 key 新内容更新当前或待显示条目，使用新身份取消旧计时影响。
- 其他操作进入 FIFO，最多保留五条待显示，溢出移除最旧待显示条目。替换操作须显式指定，保留其他待显示条目。
- 宿主负责 `.task` 计时，按 entry ID 校验关闭；页面消失或进入后台时清空，不让离开页面后的提示继续出现。
- sheet / fullScreenCover 使用自身宿主和 center。实验室验证这一策略，尚未实现全 App 的自动跨层路由；正式接入时按页面范围选择宿主。
- 支持上滑与关闭按钮，不遮罩页面；操作按钮交给当前页面处理。
- 遵循系统减少动态效果，提供实验覆盖开关；大字体下按钮移入文字列，文本不截断。VoiceOver 报读新内容，并保留横幅供用户操作、手动关闭。
- 触感默认不启用，实验打开后仍受应用总开关限制；关闭横幅不额外产生触感。

## 盘点范围和依据

场景按启动连接、登录账号、Bot 管理、对话执行、附件语音、工具建议、记忆回顾、提醒通知、插件连接、游乐旅行、调试用量外观分为 11 组。每个场景记录当前表现、源文件、建议位置、建议文案与 Bot 状态；尚无成功提示的已有操作也列为实验反馈。

`NoticeSourceIndex.json` 为静态代码匹配索引，覆盖 iOS 视图、状态模型、服务与本地 Package。索引包含错误处理、进度、空状态、确认、反馈和状态声明，条目数量不等于独立场景数量，也包含需要人工复核的候选。动态 API / provider 返回文案归入对应功能失败场景，不宣称穷尽所有运行时服务端错误。

刷新索引：`python3 frontend/ios/scripts/notice-source-index.py`。实验室及组件本身排除扫描，防止循环收录。更新场景时同时检查对应实现；源文件的行号以刷新时的快照为准。
