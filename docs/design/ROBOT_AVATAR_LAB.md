# 新版头像实验室

入口：设置 → 调试 → 新版头像实验室，位于原头像实验室下方。

独立 SwiftUI 复刻实验，不修改正式头像、旧实验室、Bot 数据或 Web 客户端。
参考 CX ArtLab 的 Agent Robot Avatar：https://github.com/CX-ArtLab/agent-robot-avatar 。
头部使用原项目的点列及圆角混合；双眼、天线的比例及表情机制参考原项目。
当前支持 17 种状态、4 种尺寸、3 种快捷配色及截图的 11 色选色卡、圆角调节、自然眨眼、视线游移、
眼神先行与头部跟随、点按重播、局部果冻形变、独立天线拖动、中心按压挤压和回弹、演示全部 17 种状态。
自动睡眠尚未复刻。
减弱动态效果时保留静态表情和即时手势反馈，不播放弹性动画；离屏、退后台和退出页面停止动画任务。
输入持续闪烁；其余动作按 Demo 的单次流程播放并恢复，睡眠保留闭眼。点击重播重新播放。

外观同时提供原有石墨 / 深紫 / 深蓝快捷选项和用户截图的 11 色选色卡。
2026-10-08：从 2026-10-07 23:31:35 截图的色块中心采样，保留 Display P3 编码。
两行顺序为黑、棕、红、橙、琥珀、绿；青绿、蓝、紫、粉、灰。
截图选色卡仅用于本实验页，不修改正式 Bot 资料的颜色枚举。
新版 11 色与三个快捷配色已逐项点击，红色选择标记与两行排列检查通过；构建通过。
选择直接更新头部与天线的主色；选色卡与快捷配色互斥高亮，仅保存在实验页。
在线 Demo 0.5.2 的 17 个按钮包含本页的 14 个基础动作、等待·环绕、喜欢、随机。
等待·环绕使用头部表面投影，眼睛经过背面时隐去；喜欢按用户要求将左右眼各自变为一颗心并轻跳；
随机是双眼滚轮动画，左右眼先后减速、回弹停下，并非随机选择其他动作。
后三项的投影与时间曲线参考上游 wrap/love/random 模块；喜欢、随机结束后恢复正常双眼。

验收：检查入口顺序、所有表情、连续状态、快速切换及重播、开始/停止演示、
拖动释放、尺寸/配色/圆角、深浅色、减弱动态效果、离屏及返回。

2026-10-07 验证：iPhone 17 / iOS 26 模拟器构建、安装和启动通过；
确认入口在旧实验室下方，最初的 14 个状态逐一切换并录屏；
32 / 44 / 96 / 160 尺寸和三种配色的控件已操作，恢复 160 / 石墨。
补齐至 17 个按钮后重新构建通过；新增动作已切换、重播并录屏，关键帧确认环绕隐去、爱心合拢恢复、滚轮先后停止；
修正头像可见性判断，避免进入页面后动画被误暂停。
8 色选色卡及三种快捷配色逐项操作通过。选动作后自动回到预览。
真机、深色模式、系统减弱动态效果、完整拖拽手感和性能仍待人工验收。

## 2026-10-08 细节校准

上游固定为 `0.5.2` / `b8b3fd497a1d103ff6f028d21769805cb76c1068`。
几何使用上游头部点列、0.9 高度压平、0.94 缩放，以及相同的圆角混合；默认圆角 50%。
动作计算在 `RobotAvatarMotion.swift`，路径与眼睑裁剪在 `RobotAvatarGeometry.swift`。
独立天线使用刚度 180、阻尼 5.6 的弹簧；动作时开启上游的闪烁周期与 80% 占空比。
天线圆心 y=12、半径 15，超出原 240 画布顶端；绘制画布四周增加 40 单位余量，
外部占位与比例保持原样。模拟器预览确认完整圆形；17 动作与四个最大拖动方向及
释放的弹簧采样均未超出扩大画布，32/44/96/160 按比例使用相同余量。

| 用户反馈 | 校准内容 |
| --- | --- |
| 天线 | 直径从 17 改为 30，位置 (120,12)，独立跟随头部、滞后与回弹、动作闪烁 |
| 发呆 | 圆眼保持，准备 800ms 后看左上 (-18,-16)、右上 (18,-16)，各停留 1400ms，再回中 |
| 等待 | 3200ms 内两次水平绕行，双眼交叉、前后深度 ±8%、横向压缩 0.72～1 |
| 输入 | 12×78、圆角 3 的闪动光标，265ms 切换一次；两个眼图层按 Demo 重叠至中央 |
| 发送 | 150/150/150/310ms 的两次点头，眼睛下移峰值 31、高度压缩 30%；头部按用户要求跟随两次轻点 |
| 警告 | 近眼放大 1.48×1.40，远眼 0.78×0.97，斜眼睑下压、停顿、抬起与恢复 |
| 审视 | 上下眼睑夹出 16 的窄缝；第一轮下、上、回中，第二轮下、回中，不额外上冲 |
| 系统错误 | 正常圆眼左右扫动 30，头部滞后左右平移 ±4，最后归中 |
| 惊讶 | 235ms 收至 34×36，175ms 扩至 68×68，420ms 微颤，430ms 恢复 |
| 喜欢 | 用户指定的圆润双心变体：两眼各自变心，不向中央合并；饱满圆弧双瓣、柔和凹口和圆底尖，保留变形、心跳与恢复节奏 |

验证：iPhone 17 / iOS 26 构建、安装、启动通过；10 项反馈涉及的动作已逐项操作并录屏。
临时 Swift 检查验证了双点头峰值与分隔、光标尺寸/周期、等待交叉/透视、警告斜眼睑、
审视窄缝、眼睛领先头部的摇头、惊讶收缩扩张恢复、分开的双心、减弱动态效果，
以及 17 个动作在 0～12 秒内的连续采样（所有尺寸为非负有限值）。
录屏关键帧用于检查实际视觉效果；真机手感及用户与 Demo 并排确认仍属于人工验收。

参考角色为 CX ArtLab 原创，本实验不声明其为 Vera 原创角色。
若未来作为 Vera 品牌角色发布，另行确认视觉使用边界或重新设计角色。

## 2026-10-08 拖拽与挤压校准

交互计算独立放在 `RobotAvatarInteraction.swift`，和表情共用页面的动画时钟。
按上游 core/gestures 参数移植，不再只对整张头像做统一拉伸：

- 从任意位置向任意方向拖动，包括斜向：以抓取点为中心的高斯局部路径形变，
  配合方向伸缩、切变、整体轻移；眼睛先看向手指，头部倾斜与天线弹簧随后跟随。
  松手保留速度并回弹，收敛后按向内/向外的拖动意图给出成功或生气的短暂反应。
- 天线有独立命中区域和拖拽状态；圆点先跟手，头顶局部形变滞后。
  释放刚度 460，阻尼从 10 逐步增加到 24；头顶跟随另用 118/330 的弹簧。
- 手机按住中心 140ms 后挤压：头部收至约 71%，双眼缩小并靠近，天线向内收拢，
  持续按压有轻微压力颤动。释放用刚度 190、阻尼 9 回弹并带细微波纹。
  手指移动超过 4pt 时转为头部拖动，保持原抓取点；短按、拖拽和挤压分别处理。
- 手势取消、换动作、离屏、退后台和退出页面清理状态；按压/拖拽释放不误触重播。
  保留扩大画布和独立天线辅助功能目标，天线拖出原视口后仍完整可见。

验证：最终 iPhone 17 / iOS 26 构建、安装、启动通过。
Swift 检查覆盖 32/44/96/160 四种尺寸和八个方向，验证局部形变强于远端、独立天线领先头顶、
短按/按压阈值/移动转拖拽、释放超调与收敛、天线完整绘制范围，以及减弱动态效果的静态反馈。
原 17 个动作的连续采样检查通过。
模拟器实际执行头部上下左右拖动、天线横向/纵向独立拖动和中心长按，并录屏查看形变、回弹和恢复；
最终调整后的眼神跟随也重新运行并录屏。真机触摸手感和与 Demo 并排验收仍待用户确认。
