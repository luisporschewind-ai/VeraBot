SwiftUI 原生复刻实验。原头像实验室继续保留旧形象作对照；新版机器人现已用于 iOS 正式头像，并消费每个 Bot 已保存的外观配置。Web 客户端不在本次接入范围。

## 2026-10-08 细节校准

上游固定为 `0.5.2` / `b8b3fd497a1d103ff6f028d21769805cb76c1068`。
几何使用上游头部点列、0.9 高度压平、0.94 缩放，以及相同的圆角混合；默认圆角 50%。
动作计算在 `RobotAvatarMotion.swift`，路径与眼睑裁剪在 `RobotAvatarGeometry.swift`。
独立天线使用刚度 180、阻尼 5.6 的弹簧；动作时开启上游的闪烁周期与 80% 占空比。
天线圆心 y=12、半径 15，超出原 240 画布顶端；绘制画布四周增加 40 单位余量，
外部占位与比例保持原样。模拟器预览确认完整圆形；17 动作与四个最大拖动方向及

## 2026-10-08 拖拽与挤压校准

交互计算独立放在 `RobotAvatarInteraction.swift`，和表情共用页面的动画时钟。
按上游 core/gestures 参数移植，不再只对整张头像做统一拉伸：

- 从任意位置向任意方向拖动，包括斜向：以抓取点为中心的高斯局部路径形变，
  配合方向伸缩、切变、整体轻移；眼睛先看向手指，头部倾斜与天线弹簧随后跟随。
  松手保留速度并回弹，收敛后按向内/向外的拖动意图给出成功或生气的短暂反应。
- 天线有独立命中区域和拖拽状态；圆点先跟手，头顶局部形变滞后。
  释放刚度 460，阻尼从 10 逐步增加到 24；头顶跟随另用 118/330 的弹簧。
- 手机按住中心 140ms 后挤压：头部收至约 71%，双眼缩小并靠近，天线向内收拢，
  持续按压有轻微压力颤动。释放用刚度 190、阻尼 9 回弹并带细微波纹。
  手指移动超过 4pt 时转为头部拖动，保持原抓取点；短按、拖拽和挤压分别处理。
- 手势取消、换动作、离屏、退后台和退出页面清理状态；按压/拖拽释放不误触重播。
  保留扩大画布和独立天线辅助功能目标，天线拖出原视口后仍完整可见。

验证：最终 iPhone 17 / iOS 26 构建、安装、启动通过。

### 状态与天线

眼睛、头部与天线偏移由同一个 Frame 和相位生成；原版闪动周期、80% 可见占空比和边界计算保持保存点。
新状态从当前可见表情在 200ms 内平滑进入；各状态观察 4800ms。
共享交互反馈结束后恢复当前状态时间线。自然动态开关只控制眨眼/视线，不重播动作或天线。

| 状态 | 循环 ms | 天线周期 ms | 表现 | 关键观察时刻 ms |
|---|---:|---:|---|---|
| 思考 | 2400 | 1200 | 眯眼向左上看，头部轻倾、天线抬起 | 0 / 200 / 1400 / 2600 |
| 召回记忆 | 2800 | 1400 | 轻抬眼左右检索，天线跟随 | 0 / 200 / 900 / 1600 / 2300 / 3000 |
| 执行工具 | 1800 | 900 | 专注眼睑，微动与工作脉冲 | 0 / 200 / 650 / 1100 / 2000 |
| 委派 | 2400 | 1200 | 向右看后点头，天线向交接方向偏移 | 0 / 200 / 1400 / 1700 / 2600 |
| 回复 | 1200 | 1200 | 双眼轻动，头部与天线按回复节奏响应 | 0 / 200 / 500 / 800 / 1400 |
| 等待确认 | 2400 | 2400 | 轻睁眼、缓慢停顿后轻点头 | 0 / 200 / 1400 / 2180 / 2600 |

减弱动态效果提供代表性静态眼睛，没有闪动和空间运动；手势保留即时反馈。
模板提供几何、眼睛与天线锚点、圆点半径、绘制余量和能力声明；共享动画维持 240 单位参考坐标。
具体新形状需提供轮廓、眼睛/配件锚点与能力范围，再登记模板；无需重写这 23 个动作。

### 外观文档与兼容

`appearance` 为独立 nullable JSON，迁移 v015 在 schema v14 的 bots 表上幂等增加 TEXT 列。
`schema_version=1`；模板 ID 为小写标识，版本为正整数；body/eyes 颜色保存 srgb 或 display-p3 与有限 [0,1] 分量；
roundness 为有限 [0,1]。禁止额外字段，编码最多 4096 UTF-8 字节。动作不写入外观文档。

PATCH 省略字段保持原配置，null 明确清除，对象替换。未来模板的合法文档可以保存；
Swift Bot 保留原始未知文档，不让整条 Bot 解码失败；未安装模板不会自动加载成机器人并覆盖原配置。
保存只更新 appearance，保留 avatar/color/照片/权限；正式 iOS 头像读取 Bot 和用量响应中的已安装外观配置。Bot 外观配置需要后端 schema v15 迁移与 Bot API 支持；运行状态到头像动作的映射只在 iOS 完成，不需要新增后端事件。
