# 机器人家族实验（2026-10-09）

用户已同意借鉴 Avatar Studio 的三点建议：以现有母版微调轮廓、独立组合形状/原色/皮肤、少量配饰验证。

## 本轮范围

- 锁定十一种轮廓：标准、微鼓、轻偏、饱满、圆形、花朵形、圆润三角形、胶囊型、五边形、南瓜形、圆润水滴形。移除圆润心型，星星恢复为上一版南瓜轮廓；圆润水滴保留用户认可的矮胖版本，其余轮廓保持当前版本，后续未经用户要求不再调整。旧心型实验配置回退到标准形状，保留皮肤与配饰。所有轮廓复用原眼睛、表情、皮肤、配饰与交互时钟。
- 在新版头像实验室的“形象与配色”中选择轮廓、纯色/四种参考皮肤、无配饰/耳机/徽章。选择在状态演示页共享。
- 十一种锁定形状已于 2026-10-12 接入正式创建/编辑流程，通过现有 BotAppearance `template_id` 保存和同步，无需扩展服务端字段。实验层的皮肤与配饰仍独立保存在本机。参考皮肤保留自己的配色，切换原色不会清除皮肤选择。
- 配饰跟随身体轮廓和变形；天线保持可见并继续表达状态。实验层不随“保存草稿到此 Bot”提交。
- 基础测试、模拟器构建/安装/启动后交给用户视觉验收；不安装实体手机，不提交或推送 Git。

## 实现与验证

1. Core：固定种子轮廓生成、十一种形状目录、独立的实验组合配置。既有三种随机轮廓保留原种子，其余形状使用明确的参数化轮廓。
2. 绘制：保留标准轮廓，新增轮廓接入同一局部形变；根据新轮廓调整天线锚点。皮肤始终先绘制，眼睛随后绘制，配饰避开眼区。
3. 实验室：共享实验选择，支持并排对比与现有全部状态演示，本机记住选择。
4. 验证：Swift 包基础测试、iOS Simulator 构建与安装。32/44/96/160 的外观、手势手感与状态视觉由用户验收。
