# UI 一致性后续方案（2026-10-13）

> 状态：后续方案，尚未实施。关闭按钮和会话列表行内对齐已在本轮单独处理；弹出页规格与行高暂不纳入本轮修改。

## 目标

统一常用弹出页面的视觉规则与列表密度，让用户在 Bot、群聊、记忆、提醒和设置流程之间切换时，能预期页面高度、导航结构、行间距和触控区域。

## 本轮已确认的范围

- 工具栏中的取消、关闭入口统一使用 X 图标按钮；保留“取消”或“关闭”的无障碍语义。
- Bot 与群聊会话列表共用同一标题行布局：名称和标签垂直居中，时间靠右，头像、标题区和预览行对齐。
- 本轮不调整弹出页面高度、弹出风格或列表行高。

## 后续建议

### 弹出页面高度与结构

按页面用途统一，而不是所有 sheet 使用相同高度：

- 创建、编辑、设置等表单型页面采用导航栈、行内标题和大尺寸 detent；页面内容较长时允许滚动。
- 头像预览等短操作保留中等高度；需要连续浏览的游戏伙伴选择保留中/大尺寸切换。
- 系统分享、照片选择和相机等系统控制保留平台原生样式。
- 对同类页面统一背景、导航栏边距、关闭按钮位置、标签栏显示策略和键盘出现时的布局。

### 列表行高与密度

保留两种密度，避免不同任务的列表被强行做成相同高度：

- 会话列表：紧凑，头像与两行文字垂直居中，标题与预览间距一致，行高足以承载稳定触控。
- 设置、成员和编辑列表：舒适，统一行上下内边距、左右 inset 和分隔线策略；头像、主标题、次要状态对齐。
- 多行文本或辅助信息出现时允许行自然增高，不裁切内容，也不改变同组其他行的对齐锚点。

## 建议检查顺序

1. 会话列表与群设置：Bot / 群聊行、群成员行。
2. 创建与编辑：创建群聊、创建和编辑 Bot、记忆编辑、提醒编辑。
3. 设置及插件：设置页、令牌连接页、插件详情中的子页面。
4. 系统弹出项：头像预览、分享、相机、照片选择和游戏伙伴选择；确认哪些应遵循应用规格，哪些保留系统原生呈现。

## 验收点

- 相同用途的弹出页面使用一致的导航结构和关闭入口。
- 内容较长时，页面可滚动，键盘不会遮住当前编辑控件和保存操作。
- 同一列表中的头像、标题、次要状态、时间和预览保持统一对齐；触控高度不因文字略有长短而不稳定。
- 在浅色、深色和原生外观下，页面背景、分组底色与文字层级一致。
- 页面按用途保留合理的高度差异，系统分享与媒体选择仍符合平台行为。

## 待讨论

- 表单型 sheet 是否一律固定为大尺寸，还是允许系统默认 detent 在小屏设备上适配。
- 成员列表是否采用与设置行相同的舒适密度，或保留更紧凑的成员浏览密度。
- 后续审查是否扩展至游乐场和通知实验室等低频工具页面。
