## 3. 尚需完成的验收

1. **文件附件**：选择 / 取消 / iCloud / 重试 / 发送 / 预览；六格式与长文非开头读取；迁移、隔离、删除、委派和提示注入保护。见文件设计 §12。
2. **提醒编辑**：只改标题、改时间 / 重复、删除确认、冲突、无日期、备注清空、DST 和跨时区。代码修复已提交，旧文档的“未提交”不是当前状态。
3. **真实授权连接**：Google OAuth、取消 / 重启保持 / 扩权 / 刷新失效 / 撤销；GitHub / Linear 的 CONN-UI-01～10 和 CONN-LIVE-01～06。需要外部测试账号与配置。OAuth 并发刷新等专项覆盖仍保留待办。
4. **真实本地向量语义召回**：明确模型实际启用、语义相近但关键词不同的检索效果。现有 M5-04 验证的是关闭向量后的回退，不能替代此项；M5-01 没有单独编号记录，不凭泛指“测试通过”补记。
5. **陪玩与旅行**：伙伴保持、头像聊天、静音、结束与重开、切账号 / 后台 / 断网；旅行各阶段、归来与相册恢复。旅行仍是本地原型。
6. **页面与平台覆盖**：启动互动、验证码 / 注册、登录和首页断网恢复、残余主题 / 标签 / 用量 / 删除消息 / 插件 UI；iOS 17/18、Dynamic Type、iPad、小屏与实机性能。以前延期条目继续保留，不因此盘点自动判失败或通过。

上述仅列未完成或缺少明确记录的项；已通过的记忆 M3/M4、M5 共享 / 反馈 / 两项修复、MCP M3 无需重复验收。

## 4. 未实现与后续方向

| 项目 | 范围 / 依赖 |
|---|---|
| Gmail 邮件工具、MCP M5～M7 | OAuth 入口不等于邮件读取 / 发送；变更审阅、自定义 URL / stdio 仍待做 |
| AUTH-M2 | logout-all 后端已存在；设置入口、忘记密码、老账号绑定邮箱待做 |
| SMS、Google / Apple 身份登录 | 尚未实现，需独立规格与外部配置 |
| APNs / 提醒后续 | R2～R4 剩余能力及真实服务端推送未完成；已有通用 MCP 卡片不代表提醒 R2 全部实现 |
| 通用持久任务主 Bot | 记忆 / jobs / scheduler / 委派已有基础；通用任务进度模型及 App 关闭后的持续推进尚未实现 |
| CI / 生产部署 | 仓库无 GitHub Actions workflow；Docker 配置已有但无实际运行验收；开机自启、共享限流、HTTPS / CORS 收敛待做 |
| 云 TTS / Web / 搜索扩展 | 云 TTS 占位；Web 继续冻结；全聊天历史搜索与搜索历史延期 |
| 文件扩展 | OCR、PPTX、多附件、分享扩展不在首期 |

列入本盘点不代表这些方向获准实现或已有排期。
