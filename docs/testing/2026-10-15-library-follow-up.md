# 2026-10-15 资料库验收问题修复

## 范围

按用户确认的五项调整：资料库入口移至左上角头像设置页；修复全局与 Bot 图片预览和下载；Bot 设置列入 Segment；恢复原有 Bot 表单布局。

## 原因与改动

- 原版本图片网格只读已下载原件，没有单独请求预览。现在调用带鉴权及令牌刷新能力的 `/api/library/items/{id}/thumb`，并按账号和资源版本缓存到本机。已下载原件优先使用，原件 Wi-Fi 自动/蜂窝手动的策略不变。
- 模拟器日志显示后台下载服务以进程缺少 bundle ID 拒绝连接；旧模拟器安装包确认为未签名。新模拟器构建使用 ad-hoc 签名。
- 手动下载改用前台会话，不再等待后台服务；点击时可替换等待中的自动任务。取消旧任务按 job UUID 匹配，避免迟到的取消操作把新任务一并取消。
- 移除首页会话列表的资料库行，放入头像设置页。Bot 详情复用原 BotEditView，保留头像、昵称、标签和设置内容顺序；默认“设置”，与“文件”“图片”并列，右上角保留原表单的保存按钮。

## 追加调整

按用户后续要求，Bot 页面移除开始对话、提醒、协作记录入口；主 Bot 操作合入昵称/标签卡片，任务保留独立入口。形状选择在 Bot 设置中使用紧凑网格，头像由 44pt 改为 36pt，格子最小高度从 68pt 压至 48pt、间距由 8pt 压至 4pt，并减少分区留白；其他使用方保留原尺寸。

## 构建注意

本地模拟器需要保留签名：本轮使用 `CODE_SIGN_IDENTITY=- CODE_SIGNING_ALLOWED=YES`。不要沿用旧的 `CODE_SIGNING_ALLOWED=NO`，以免后台传输服务再次拒绝连接。
