# 移动端 SQLite 离线持久化

## 当前状态

按已确认的 SQLite + 独立数据访问层方案完成实现；初始记录未验证，2026-10-12 集成时已完成完整 Swift 包回归、后端相关回归与审查修复，并完成模拟器/备机安装。当前结果统一见 [Main 集成交付](2026-10-12-main-integration.md)，设备交互验收仍需单独记录。

## 实现范围

- iOS 本地 SQLite 数据库按规范化服务地址和用户 ID 隔离，令牌不进入业务库；启用 WAL、事务、文件保护和备份排除。
- Bot/群列表、完整私聊/群聊历史、草稿、流式消息中间状态保存在本地。打开对话时先恢复本地内容，再从服务端继续同步。
- 后端 schema v21 为私聊与群聊提供修订号和分页一致性检查；客户端持久化暂存页与游标，完成整轮后再原子对账。
- 清空/删除及账号或服务器切换会使旧同步失效；私聊 `done` 未确认的消息保留原文，不自动重发或猜测服务端对应关系。群聊沿用现有请求 UUID 恢复流程。
- 图片/文件原始字节缓存、私聊自动补发不在本轮范围内。
