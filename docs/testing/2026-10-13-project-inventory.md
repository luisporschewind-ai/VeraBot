## 2. 已实现能力与实际边界

- **账号与 Bot**：账号隔离、Keychain 与令牌刷新、多个 Bot、人设、工具/委派白名单、记忆权限、置顶与外观。没有账号级主 Bot 字段、选择接口或身份徽章；置顶与游戏助手关联都不能代替主 Bot。
- **私聊**：SSE、工具调用、附件、委派和审计。`agents/runtime.py` 是一轮对话执行入口；它没有通用持久任务/步骤及等待用户后恢复机制。不能直接把 `run_chat` 当后台任务入口，以免伪造用户消息或沿用请求生命周期。
- **记忆 M1–M5**：提议/确认、滚动摘要、风格、候选、成长/回顾/导出/引用及混合召回已有实现。M3/M4、M5 共享/反馈及修复的用户验收沿用既有记录；真实本地向量语义效果仍需单独验收。`memory_jobs` 仅处理 summarize/extract/review，不是业务任务引擎。
- **服务端定时任务**：API + 独立 Scheduler/Worker、SQLite 队列、租约与续租、版本/幂等、短暂提供者失败重试、结果持久化及消息/通知去重投递已进入 main。后台只开放天气、提醒列表及服务端认可的 MCP 只读工具；不支持委派、写工具、任务自修改、附件或等待用户。已确认记忆可按权限召回，但不读取整段私聊历史。
- **定时任务恢复语义**：pause/resume 是排程暂停/恢复，不是恢复原来执行到一半的工作。租约过期标 interrupted；不自动重放不确定的模型请求。普通工具错误会使本次失败；目前只有 provider_temporary 进入自动重试。
- **联网搜索**：免搜索 API key 的公开网页搜索与安全正文读取已合入 main；存在权限、次数、时间与访问验证边界。真实匿名网络成功记录不代替真实模型及 iOS 引用交互验收。定时任务 `policy.BUILTINS` 当前不包含 web_search/web_read_result，不能把私聊可搜索等同后台已可搜索。
- **MCP 与确认**：M1–M4、冻结参数确认/取消及状态回读已有实现；真实 OAuth 仍待验收。`actions.confirm` 执行单个 MCP 操作并写结果消息；没有关联持久业务步骤、自动唤醒下一步的协议。Gmail 连接入口不等于邮件工具。
- **主线群聊**：正式文字/图片/文件、点名/全体讨论、语义路由、停止和成员重试已有代码；仍保留默认回应者，路由失败回退默认成员。执行绑定请求，群内没有联网、工具、私聊、长期记忆和持久交接。群 v2 工作树是后续实现，不应用主线测试替它验收。
- **iOS 本地持久化**：账号/服务器隔离的列表、分页历史、草稿及修订同步已有实现；离线查看不等于手机承担后台执行。尚无定时任务管理页或通用任务页。
- **通知**：站内收件箱、偏好、免打扰、去重/限流和提醒本地通知已有实现。APNs 真推送尚未实现；无法承诺 App 关闭后立即收到新产生的任务求助。
