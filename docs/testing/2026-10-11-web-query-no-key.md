# Bot 无 key 联网：修订与验收

2026-10-11。独立工作区 `/Users/admin/.codex/worktrees/bot-web-query/VeraBot-v0.1`；未提交、未合并、未推送，未改主工作区。

用户明确要求像用户一样直接搜索公开网页，不配置搜索 API key；新闻优先国内、其次国际。原 Tavily 方案已删除。

## 当前实现

- Playwright 1.63.0 + Chromium 匿名独立会话访问 Google 公开搜索页；访问验证或网络故障时转 Bing 公开搜索。每次新建上下文，不读取用户浏览器 Cookie、账号或历史；页面请求只允许固定搜索与静态资源域名，阻止 ServiceWorker 和 WebSocket。
- 搜索不读取、不检查任何服务 API key。服务默认启用，Bot 的工具权限仍由用户逐一开启。浏览器缺失、访问阻断、无结果会返回各自状态，不伪造结果、不绕过验证码。
- Google 验证冷却 5 分钟，备用请求不延长冷却；Bing 不支持的年范围会保留原错误，不悄悄去掉过滤条件。来源保留实际搜索引擎、原始链接和查询时间；没有可验证发布时间时记为未知。
- 正文只读取本轮返回的公开 HTTPS 链接。每次检查 DNS 的全部地址并固定连接 IP，保留原主机名做 TLS 验证；每次跳转重新检查。正文不执行网站脚本，限制响应体 1 MiB、正文 4000 字，拒绝非 identity 压缩。
- 网络预算：每轮搜索最多 2 次、正文读取最多 3 次、总计 45 秒；单次搜索 30 秒、正文下载 12 秒。额外的每日 50 次是负载保护，不是付费额度。
- 当前网络环境把部分 DNS 结果映射到 `198.18.0.0/15`。只有解析结果全部属于该保留网段时，正文读取才使用固定 Google Public DNS over HTTPS 查询该公开主机名；返回的地址仍须全部是公网地址，连接仍固定到已验证 IP 并校验 TLS。系统 DNS 中出现真实私网地址或公私混合结果时不会触发此回退。此解析不使用账户凭据或 API key。

## 真实网络结果与边界

- 后端匿名 Chromium 的 Google 搜索遇到访问验证，未尝试绕过；随后同一后端匿名 Bing 国内新闻查询实际返回 5 条链接，包含腾讯新闻、央广网、云南网和新浪。匿名 Bing 普通资料查询也实际返回 10 个结果，包含 Python 官方站；另一次匿名 Bing 国际新闻搜索曾返回 9 条链接。
- 安全正文读取成功取得新华网公开文章 1377 字，以及 Python 官方文档 3703 字。国际新闻结果中的一个 MSN 页面只提供客户端脚本，没有可读取正文，因此按无正文处理。
- 国内新闻与普通资料均已有后端匿名搜索成功证据。进入 Google 验证冷却后的 Bing 普通查询返回10条且标题正常；把 Google 首屏等待缩短至2秒后，冷启动完整供应商查询在20.22秒返回同样10条结果。单次搜索预算30秒、整轮45秒；各场景仅有少量真实请求，连续稳定性仍待验收。用户浏览器曾能在 Google 中看到新华网、凤凰网等结果，但该浏览器结果不等同于后端匿名会话证据。
- 没有调用真实模型；模型能否稳定遵循国内优先策略及最终引用呈现仍未验收。
- 本轮 iOS 更新构建成功；独立模拟器重新安装时遇到 NSMachError -308（服务进程退出）并进入 Shutdown，因此更新后的安装启动验收未完成。

实时临时证据在 `/tmp/verabot-web-world-live.json`、`/tmp/verabot-web-no-key-*.log` 等文件中，可能随运行环境清理。一般网页需要 JavaScript 或要求访问验证时，安全正文读取无法取得内容。
