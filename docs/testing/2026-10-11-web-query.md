## 新闻偏好调整
2026-10-11 用户确认国内优先、国际其次，已更新运行时规则与工具说明。默认首次查询中国国内新闻，综合新闻或国内结果不足时再查询国际；明确指定国际或地区则遵从用户。来源不固定在少数媒体，国内与国际分开呈现。调整后重新运行联网离线回归，22/22 通过，`git diff --check` 通过。此项为模型策略，离线测试未证明真实模型会按地区顺序检索，真实模型遵循程度仍需验收。

真实验收用例：今天国内新闻、国内外综合新闻、只查国际新闻、指定媒体新闻、国内无结果。供应商选型先评估国内中文结果质量、覆盖、发布时间与正文读取，再评估国际结果。

## 配置与真实验收
默认不可用；在后端的私有环境配置 `VERABOT_WEB_ENABLED=1` 与 `TAVILY_API_KEY`，重启后，在指定 Bot 的工具权限开启“联网查询”和“读取查询资料”。密钥不要提交 Git 或输入聊天。`VERABOT_WEB_DAILY_REQUESTS` 默认 50（UTC 每日外部尝试，失败也计数），0 禁用。

Tavily 暂为候选，尚未进行 Tavily/Brave 中文结果质量、可达性、延迟和费用的真实比较。没有调用真实搜索服务，也没有消耗真实模型 Token。来源引用语义准确性、新闻时效、付费额度、真实模型按需调用及原生页面交互待人工/真实服务验收。

API 参数参考：[Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。这些参考不能替代真实环境的契约验收。
