## 验收结果

| 项目 | 操作与结果 | 结论 |
|---|---|---|
| 确认卡片 | 输入测试指令并发送；页面显示「需要你确认」、服务与工具名、破坏性标识、参数、过期时间，以及执行 / 取消按钮。action #1 为 pending，远程调用 0 次 | 通过 |
| 取消 | 点击「取消」；页面显示「已取消」，action #1 为 cancelled，远程调用仍为 0 次 | 通过 |
| 重启恢复 | 再次发送测试指令产生 action #2；终止并重启 App，重新进入 Bot 对话，待确认卡片与按钮恢复 | 通过 |
| 执行 | 点击恢复后的「执行」；页面显示「已执行（约 154 字）」，action #2 为 done；MCP 收到 1 次调用，参数与卡片一致 | 通过 |
| 重复确认 | 对已执行的 action #2 再调用确认接口，返回 HTTP 409；远程调用保持 1 次 | 通过 |
| 协作记录 | Bot 详情 → 查看协作记录；页面显示「已确认执行」「工具调用」「已取消」及工具名称 | 通过 |
