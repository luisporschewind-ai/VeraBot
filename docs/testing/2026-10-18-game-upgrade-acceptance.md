# 游戏改版统一验收清单

日期：2026-10-18。关联[执行基线](../superpowers/specs/2026-10-18-game-upgrade-execution-baseline.md)与[唯一进度总账](../tasks/2026-10-18-game-upgrade-progress.md)。

2026-10-19当前结论：右侧Bot/蛇/原触感旧包已有双机安装记录；新增掌机v2与音效v1已进main但存在原计划缺项，尚未找到这次新功能的双机交付/试听/用户验收记录。新规则/陪玩及云端未见实现。后续集成文档称模拟器构建安装通过，原任务首次未构建记录保留；本轮没有重跑构建/测试或代签人工通过，复选框继续保持未勾。详见[核对记录](../tasks/2026-10-19-game-plans-progress-audit.md)。

## 记录格式

每项记录：版本号、构建时间、源码HEAD及未提交范围、安装包/可执行文件哈希、设备型号/系统、步骤、预期、实际、Pass/Fail/Blocked、证据路径、验收人。保留未通过项；安装成功和进程存在不能替代游戏内验收。两机主/备分别记录，不从一机结果推断另一机。

## V-01：完整布局与入口（D1、L2）

- [ ] 主机/备机进入游乐场→俄罗斯方块：完整20行、下个方块、右侧当前Bot、数据和全部操作同屏可见；没有顶部陪玩大卡片，无棋盘遮挡或为操作而滚动。
- [ ] 收到短气泡、暂停、恢复、终局后比较棋盘边界：位置/尺寸不跳动；照片头像正常，不替换为图中示意机器人。
- [ ] L2完成后确认十字键/斜排A/B/START/SELECT与v2映射；上臂/中心无动作；菜单包含玩法/重开与保留的陪玩入口。当前已安装原五键版本不能作为本项通过证据。
- [ ] 深色、原生主题、减少动态效果与系统大字体；额外以320/375/414pt布局预览核查最小命中区，不缩小文字到不可读来凑空间。无重叠按钮和不可达菜单。

## V-02：输入、实体触感与生命周期（D3、L2）

- [ ] 轻点左/右/缓降各一次；按住应在180ms后重复、70ms节拍；松开/滑出立即停止，无抬手双震。A每次旋转一次，B只硬降一次。
- [ ] 快速左右交替、多指同时按左右、释放最新键、在按压中打开菜单/聊天/切伙伴；旧方向不粘住，无跨暂停补发。
- [ ] 长按中锁屏、切微信、返回、离页再进入、重开：旧计时器不再推动当前局；暂停方向/A/B不操作、不震动。
- [ ] START暂停→继续倒数，倒数中再暂停或进后台，取消后保持暂停；菜单/聊天关闭不会自行继续。
- [ ] SELECT菜单重开→取消，局面保留且暂停；确认重开才新局，旧输入/倒数/模型回应清空。
- [ ] 触感开关关闭后所有游戏键不震；开启后普通与硬降轻重可辨。减少动态效果关闭位移/弹跳，保留静态明暗；真实手感由用户判断。

## V-03：Tetris规则（L1保留回归，L3升级后执行新规则项）

- [ ] 先记录专项自动测试输出：得分100/300/500/800、缓降+1/格、硬降+2/格、一次落定仅一次计分，失败动作不产生成功事件。
- [ ] L3后观察ghost与硬降落点相同；贴墙/贴地/堆叠旁旋转符合固定kick，阻挡不瞬移，O旋转不改变位置或续时。
- [ ] 测500ms触地微调、15次上限、硬降立即落定；清行180ms输入锁定、暂停冻结余时，再继续不重复清行或生成两块。
- [ ] ready等待开始，终局不能被resume复活；新局清空旧任务。包测试覆盖袋序、相同seed、拆分时间推进与序列化恢复；不能只靠试玩几块宣称随机/计时已验证。

## V-04：陪玩（D1现有能力，L4新增能力另记）

- [ ] 点头像/聊聊先暂停；可手动交流、换伙伴、安静、错误重试，返回保持暂停。普通头像与照片头像均可操作。
- [ ] L4后单行、多行、进入危险区、暂停、终局反应明确但不过密；危险15进入、≤12退出，持续危险不逐块警报；减少动态效果可用。
- [ ] 自动发言最多3次且间隔≥30s；局中最多2次，保留终局机会；失败计次，换伙伴不补额度，重开才重置；终局撞冷却时“本局回顾”仍可点。
- [ ] 安静关闭主动文字，手动聊仍可用；气泡5s收起且完整文字能在面板查看。断网只影响陪玩回应，不冻结纯本地游戏。
- [ ] 重开、换伙伴、切账号后制造迟到回复/表情回调：旧内容不出现；不写普通聊天和长期记忆，不编造具体摆放位置。

## V-05：贪吃蛇备用与跨功能回归（D2、D3）

- [ ] 进入不自动移动；开始后滑动/方向键都可用，快速两次转向按节拍应用，不直接反向。
- [ ] 吃食增长加分，逐档加速；暂停/继续、玩法面板先暂停、碰撞结算与重开可用；返回保留本机最佳。
- [ ] 离页/后台自动暂停；重进为新局，不显示跨次恢复承诺；不同账号/后端的最佳记录隔离。
- [ ] 原有蛇规则专项保持10项行为覆盖；Tetris改版不改变蛇规则。按钮触感依设置生效，满盘胜利由确定性测试验证。

## V-06：音效（A1–A4完成后）

- [ ] 8项最终素材存在、许可与原始/处理哈希齐全、格式/时长/峰值/1MiB目标有脚本结果。候选试听、最终选择分别记用户结论。
- [ ] 首音/连点/硬降接清行/吃食/终局声：没有重复点击层、爆音或积压；自动重力/蛇每格移动安静；五分钟体验不疲劳。
- [ ] 软件事件→play调用100次p95≤16ms仅作为分发指标；扬声器和耳机实际听感另记，不能用该指标冒充声学延迟。
- [ ] 游戏音效开关、系统静音、触感独立；别的音乐不断；TTS/录音优先，旧音效释放不会结束新录音。
- [ ] 耳机断开、来电/中断、后台/锁屏、离页立刻停声，不自动外放或补播历史；用户再次显式开启才解除断开后的静默。

## V-07：真实云端接管（C1–C5完成后）

- [ ] 同一当前方块交出→查询确认权威controller=bot、持久版本增加；方向/A/B禁用，状态明确；重复点击只有一个操作。
- [ ] 分别切微信、锁屏、终止App后等待约2分钟，从服务事件/逻辑时间证明真实推进，再进App是同一局；若自然结束，记录真实终局且不自动新开。
- [ ] POST响应丢失、请求超时、切网络：本地冻结，按同requestID查询；不恢复旧盘或创建第二局；worker不可用时不显示托管成功。
- [ ] Bot运行时“我来玩”→服务端冻结/安全清行/交回→同步→倒数→本地；收回请求后旧worker不能再提交，响应丢失仍可查到同一次结果。
- [ ] 代玩时打开聊聊/换伙伴，收到服务暂停确认后才开；关面板不自动继续；手动暂停/继续、安静模式与游戏音效设置不混用。
- [ ] 杀worker、重启API、租约过期、DB写失败后无双控/回退已显示版本/重复结算；停机一小时不快进死亡；planner不依赖模型可用性。
- [ ] 其他账号404、非原client只能读不能收回、非法快照/旧ruleVersion拒绝；同request不同内容409；两端fixture一致。
- [ ] 分段玩家/Bot贡献与总成绩相符，进行中不清理，结束7天后清理及删账号清理有临时DB测试证据；不混入纯手动成绩。
- [ ] 独立worker监督/容量/心跳/状态命令可用，16局负载不达目标则实测收敛容量；迁移有备份/幂等/恢复记录，不以API进程或手机前台存活当作后台运行证明。
