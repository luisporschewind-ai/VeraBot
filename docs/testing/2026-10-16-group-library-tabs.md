# 2026-10-16 群设置文件、图片分页

## 范围

群设置在原头像与名称下增加“设置 / 文件 / 图片”三个 Segment，默认设置。成员管理、停止讨论、清空历史、删除群聊和保存流程保留。资料页复用现有文件列表、图片网格和详情，只增加本群来源筛选，不增加群上传、共享或批量管理入口。

## 资料筛选

以资料来源中的 `kind=group` 和 `source_id=当前群 ID` 判断归属，不以群成员 Bot 的关联资料代替。离线缓存、名称搜索及在线正文搜索使用同一筛选。来源原消息已清空但资料仍保留时，继续显示在本群分页中。

复用已有全局资料目录与下载缓存，不增加后端接口、表或迁移。
