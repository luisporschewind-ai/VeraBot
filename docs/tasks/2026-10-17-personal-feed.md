# 2026-10-17 Bot 个性化 Feed

## 请求与范围

用户确认「一个用户 Feed、多个 Bot 按需供稿」初版方案，要求新增底部 Tab 并开始实施。新增入口名称「发现」，与现有「探索」并存。

工作位于独立工作区（当前 `/private/tmp/vb-b`，分支 `feat/personal-feed`），基于 main `2564282`。主目录中附件、多图和短回复改动保持原状。

设计与接口：[设计](../superpowers/specs/2026-10-17-personal-feed-design.md)。执行与进度：[计划](../superpowers/plans/2026-10-17-personal-feed.md)。

## 执行决策

- 首批采集为公开 RSS / Atom / enclosure，以真实来源覆盖新闻、短帖、视频和音频模型；有凭据要求的平台不伪装已接入。
- 选源先使用权限过滤后的记忆和显式主题匹配可编辑来源目录；用户确认启用后才采集。后续再扩展全网发现和平台专用连接器。
- 摘要依据真实标注：当前可提供来源简介与订阅中实际附带的正文；本版不声称自动读完视频、转写音频或已生成模型摘要。
- 采集后台独立进程，持久化租约与队列，不要求 App 常驻；不复用聊天输出创建虚假用户消息。
- 不自动合并 main、不推送、不升级正式库、不替换当前真机验收 App。联调使用隔离数据；模拟器构建与用户验收分别记录。

## 进度

- 设计、接口、后端 v36、独立 worker、iOS「发现」Tab 与问 Bot 草稿已实现并提交。
- 后端 Feed 单测 32 项通过（含 SSRF 歧义主机名、计划 use_memory 关闭、在途暂停/租约）。隔离 HTTP 联调与真实四类来源采集此前已通过。
- Swift Kit / Intel 模拟器构建与原生界面检查此前通过；共享草稿修复见 `858d368`；ChatView 类型检查超时已拆分 body（待控制方重编确认）。

## 本版未纳入

- 需凭据的平台连接器（如 X 账号 / 付费源）与全网自动发现。
- 视频/音频自动转写、模型摘要生成、站内媒体播放器。
- 逐条推送通知；收藏原文复制进资料库。

## 验收入口

底部「发现」及隔离测试环境：关注计划、真实采集、详情/原站、收藏/已读/不感兴趣、来源暂停、问 Bot 草稿。结果见 [测试与交付](../testing/2026-10-17-personal-feed.md)。
