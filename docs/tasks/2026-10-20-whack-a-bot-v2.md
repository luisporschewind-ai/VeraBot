# 2026-10-20 · 打地鼠：洞口层次、全配色与困难模式

## 用户确认

用户要求并确认：

1. Bot 从椭圆内部冒出/缩回，前沿遮挡身体，具有真实洞口的前后关系。
2. 使用现有全部 Bot 配色随机出现；普通模式维持既有得分/时长/节奏规则，只改为全色域随机。
3. 新增困难模式：九个洞口每局随机配色、局内固定，Bot 每次出现随机配色；同色 +10、异色 −10、最低 0；空点与漏掉不扣分。上述细节通过本次异步问题由用户明确选择「采用此规则」。
4. 开局、暂停时九宫格都可见；中间提示使用半透明模糊玻璃，不能整块遮挡中间一行。

## 实现边界

- `BotAvatarColorPalette.all` 为现有 14 种配色，保留各自 sRGB / Display P3 色彩空间。颜色保存在每次探头的目标数据中，帧更新/暂停不会重新随机。
- 普通模式洞口继续中性色，任何 Bot 命中 +10，既有普通最佳记录原 key 保留。
- 困难模式从全配色打乱选九个洞口颜色，局内固定。Bot 独立从全部配色均匀随机，可能同色，也可能异色；不保证每次出现都是可得分目标。洞口显示颜色名，无障碍标签同时读出洞口与 Bot 颜色。
- 异色目标判定后也进入 220ms 反馈/缩回阶段，同一目标不能再次扣分；无效旧目标 ID、空点、重复点击不扣分。命中率只把得分命中计入分子。
- 普通/困难切换现可在任何状态使用（后续用户反馈后解除原禁用限制），切换清空本局并回到准备状态；分别保存按账号/服务器隔离的本机最佳，不修改既有普通记录。普通模式延续实时最佳；困难模式按完整一局的最终分数记录最佳，避免中途高分在错色扣分后仍被计为最终成绩。
- 洞口分为暗色内壁/远沿、Bot、近沿三层；Bot 受「椭圆内区域与洞口上方区域的并集」裁切，出现与离开都沿同一洞口运动，不从整块格子底部滑入。
- 单个游戏时钟驱动出入洞进度，不为每个 Bot 新建持续动画任务；系统减少动态效果时直接显示静态姿态。
- 中间提示改为短文案、小范围、低不透明度超薄材质，不移除/隐藏任何一行洞口。暂停仍冻结当前目标、颜色及动画位置。
- 复用音效与触感开关；正确命中保留轻触感，错色使用错误触感和既有短音。
- 本次在独立分支 `codex/whack-a-bot-v2` 实现；现已按用户要求合入本地 Main。不改后端、数据库或部署。

- 困难模式九个洞口显示不同随机配色，当前一局保持不变；只点同色 +10、点异色 −10，最低 0。
- 开始前、暂停时完整九宫格能透过提示玻璃看到，继续后 Bot 与倒计时恢复。
