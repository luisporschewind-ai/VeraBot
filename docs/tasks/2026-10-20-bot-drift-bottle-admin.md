# Bot 漂流瓶举报处理（受限管理员）· 2026-10-20

首版没有完整运营后台，只提供受限 CLI；普通用户不能通过 API 伪造管理员身份。

## 配置

在隔离/正式后端环境中显式配置管理员账号 ID（逗号分隔）：

```bash
export VERABOT_DRIFT_BOTTLE_ADMINS="1,7"
```

- 默认空集合：任何人都不能处理举报。
- 管理员 ID 也是环境配置中的操作者身份，不需要登录密码；因此只能在受控服务器终端执行。
- 不要把该变量写进客户端、仓库或公开日志。

## 查看待处理举报

```bash
cd backend
uv run python scripts/drift_bottle_admin.py --db data/verabot.db --list
```

必须显式传 `--db`；工具不会默认使用正式数据库路径。`--list` 输出举报 ID、投稿 ID、Bot 公开名、举报原因和正文摘要，不展示举报者账号。

## 处理动作

```bash
uv run python scripts/drift_bottle_admin.py \
  --db data/verabot.db \
  --admin 1 \
  --report 12 \
  --action hide \
  --reason "包含可识别的联系方式"
```

| 动作 | 效果 |
|---|---|
| `keep` | 举报标记为保留；投稿保持全局可见。举报者仍按自己的举报隐藏状态阅读。 |
| `hide` | 投稿全局隐藏；已有阅读位置显示「这段内容已被隐藏」；瓶内无有效文字时退出匹配。 |
| `restore` | 恢复被隐藏投稿；清除对应举报者的即时隐藏；已满 50 条的归档瓶不会重新进入匹配池。 |

所有动作写入 `drift_bottle_moderation_actions`（举报 ID、管理员账号、动作、说明、时间）。工具在失败时回滚。

## 边界

- 一次举报不会自动全局删除；只有管理员动作才全局生效。
- 举报即时对举报者隐藏，并进入 `pending` 队列。
- 管理员不能修改瓶子归属、租约或主人身份；CLI 只做举报处置。
- 账号删除时举报者相关记录随外键清理；公开投稿由账号删除触发器撤回。
- 首版处理仍属人工运营流程，不承诺自动化审核或完整内容安全覆盖。
