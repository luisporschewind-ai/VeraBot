# 多图卡片点击与查看页布局细化

日期：2026-10-16

## 用户要求

1. 被叠住的图片，露出部分也可以点击查看对应图片。
2. 整体在上一版基础上再缩小 10%。
3. 查看页页码位置下移，扩大中间与顶部的图片区。

## 调整

- 每层真实图片独立处理点击，保留前后遮挡顺序；点击露出的下层卡片时记录该图片索引，并直接打开相应页。
- 查看页 `TabView` 与选择索引绑定，每页设置明确的索引标签，左右翻页同步更新页码。
- 卡片宽高从原单图的 75% 调为 67.5%（上一版再乘 0.9），常见图片宽 180pt → 162pt；层间偏移和外侧留白同步乘 0.9。
- 移除查看页独立导航标题栏，将「完成」按钮浮在右上方；图片可使用更大的顶部与中部区域。
- 页码由图片下方的跟随布局移到页面底部固定位置，取消重复的系统分页圆点，保留一处「当前 / 总数」。仍遵守安全区。
- 图片左右留白从各 16pt 减至 8pt，高度改用剩余完整图片区，保留等比完整显示和横屏高度限制。
- 真机版本 0.1.0 (2026101608)，同步主辅机继续验收。保留此前未提交的附件与短回复修改。
