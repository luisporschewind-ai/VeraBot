# 游戏按钮实体按键触感

日期：2026-10-18。用户要求：按钮点击要有震动，模拟实体按键手感。

## 实现范围

- 贪吃蛇：四方向、开始/暂停/继续/再玩一局、重开。
- 俄罗斯方块：左右、软降、旋转、硬降，以及暂停/继续、重开。
- 共用 `GameButtonStyle`，保留系统 Button 的点击、取消、禁用和无障碍行为，不额外叠加手势或改变游戏动作触发时机。
- 按下时轻微下移 2pt；底部 3pt 基座、边缘和压暗反馈表现按键行程；松手通过短弹簧动画回正。
- 在按下沿触发一次短促 impact，普通键为 medium / 0.65，硬降为 heavy / 0.85；松开不额外触发，不在持续按住或游戏自动推进时重复震动。
- 沿用“设置 → 触感反馈”统一开关。禁用键不震动；减少动态效果开启时取消按压位移和弹簧，保留静态明暗反馈。
- 保持现有浅色、深色和原生主题；实色主操作使用 `brandFill` 保证文字对比度，原生模式保留中性底与主文字色。

非游戏页面按钮、游戏规则、计分和 Bot 机制不在本次修改范围。

## 代码

- `frontend/ios/VeraBot/Core/UI/Haptics.swift`：给现有触感包装增加可选条件闭包，默认仍为 true，保持原有调用行为；加入共用游戏按键样式。
- `frontend/ios/VeraBot/Features/Playground/SnakeGameView.swift`：接入对应操作按钮。
- `frontend/ios/VeraBot/Features/Playground/MiniGameViews.swift`：接入俄罗斯方块操作按钮。
