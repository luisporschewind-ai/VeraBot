## 建议顺序

### 0. 发布与质量底座

- 建立 CI：后端 mock 测试、VeraBotKit `swift test`、iOS Simulator `xcodebuild`。
- 验收：干净 macOS runner 可重复构建；CI 不触发 UI 自动化或真实模型调用；失败能定位到具体 job。
- 前置：确认 GitHub Actions runner 与 macOS 构建额度 / 成本。

### 1. 安全与本机部署边界

- iOS Keychain、令牌刷新、旧 Token 迁移及登录锁定已实现。剩余为 Web HttpOnly Cookie（先决定是否继续维护 Web）、多实例会话与生产部署验证。
- 登录已有进程内 IP 限流和持久账号锁定，模型已有每日预算；剩余为写接口与高成本调用的独立限流，以及多 worker 共享限流。
- 明确开发局域网 HTTP 与生产 HTTPS 配置，收紧生产 CORS；iOS ATS 例外仅保留在开发配置。
- Docker：启动可重复的数据库卷、环境变量和健康检查；构建并实际运行镜像后记录结果。
- macOS 后端常驻：在 Docker 方案与 launchd 之间先选定唯一主要部署方式；若面向本机用户，launchd 支持崩溃重启和日志轮转。
- 验收：登录态不泄漏；跨用户隔离回归通过；限流返回稳定错误；生产配置拒绝明文与宽 CORS；重启后数据保留。

### 3. 附件验收

- **图片 / 拍照已实现并验收**：用户于 2026-10-07 确认，真实视觉模型请求与 caption 持久化已有通过记录。
- **文件附件已实现，待验收**：PDF/TXT/MD/CSV/DOCX/XLSX，10 MB，单消息一个文件；文件选择、抽取、长文分段、Quick Look 已接入，parser 超时 15 秒。
- 剩余按 [FILE_ATTACHMENT_PLAN.md](design/FILE_ATTACHMENT_PLAN.md) §12 验证设备交互、六类样例、真实 Bot 长文读取、隔离 / 迁移 / 删除与委派授权。
- OCR、PPTX、多附件、分享扩展和 Web 文件能力不在首期范围。

### 4. 云端 TTS

- 选定供应商、语音、语言、超时/缓存策略、费用预算和密钥配置；实现 `/api/tts` 与 iOS `CloudTTSEngine`，本机 TTS 保留为回退。
- 验收：网络失败回退、取消播放、语言与音色可用、音频不被误记入对话正文、额度与隐私行为可说明。

### 5. Web 客户端方向决策

- 在实现 Web UI 前决定是否继续维护 Web：若继续，先列出必须追平的权限编辑、协作记录、设置/TTS、记忆确认、头像/标签/置顶等能力；若仅用于 API 验收，则维持冻结并避免复制 iOS 交互。
- 验收：明确维护责任、支持矩阵和最低安全标准后才开实现任务。
